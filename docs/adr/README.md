# Architecture Decision Records

ADRs record consequential decisions that constrain Pivot across releases. They
are immutable once accepted: later changes add an ADR that supersedes an earlier
one rather than rewriting history.

Each ADR uses the sections **Title**, **Status**, **Context**, **Decision**,
**Consequences**, and **Alternatives considered**. Proposed decisions begin as
`Proposed`; the records in this foundation are `Accepted`.
